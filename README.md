### 🤖 AI & Agentic Engineering

- **[ModelsDesk](https://github.com/talha7k/modelsdesk):** Open-source Rust CLI that manages **9 local inference engines** (MLX-DSpark, llama.cpp, vLLM, SGLang, TabbyAPI, Ollama…) with **auto-configuring speculative decoding** — it picks the right DSpark/DFlash drafter head for your model, zero config. One command wires the local server into **9 coding agents** (jcode, Codex CLI, OpenCode, Zed, Cline, goose, aider, crush, Continue). Published to npm + crates.io.
  ```bash
  npm install -g modelsdesk   # 60 tok/s from a 2B model on a 16GB Mac
  ```
- **Agentic Workflows:** Autonomous agentic loops, function-calling pipelines, RAG systems, and structured AI integrations in production.

### 🚀 Key Projects & Open Source

- **[Kampodra](https://github.com/talha7k/kampodra):** Lightweight, registry-free single-VM deployment engine — zero-downtime, SSH-pipelined blue/green deploys with podman/bare binaries. `cargo install kampodra` or `brew install`.
  ```bash
  kampodra deploy --blue-green   # ship to any Linux VM over SSH, no registry, no k8s
  ```
- **[@talha7k/zatca](https://www.npmjs.com/package/@talha7k/zatca):** Production ZATCA e-invoicing compliance library for Saudi Arabia — Phase 1 & 2 (UBL generation, cryptographic stamping, QR codes, ZATCA portal integration). Used by real invoicing systems.
  ```bash
  npm install @talha7k/zatca     # Fatoora compliance in a box
  ```
